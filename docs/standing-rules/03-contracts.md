# 3. Исполнимые контракты

Источник: сначала инвентаризация `01-inventory.md`, затем сформулированное поведение `02-desired-behavior.md`. Контракт описывает условие, действие, проверяемый результат и восстановление при ошибке. Он применяется к затронутому решению соразмерно задаче. Краткий прогноз допустим; публиковать подробное внутреннее рассуждение или создавать отдельный файл для каждого шага не требуется.

## Общие шаги

| Шаг | Действие | Условие завершения |
| --- | --- | --- |
| S1 | Восстановить исходную цель, режим, требования, изменения и полномочия | Следующее действие соответствует актуальному поручению и всем совместимым требованиям |
| S2 | Прочитать решающие источники, инструкции подходящих skills, схемы нужных tools и зависимости | Существенные предпосылки следующего действия имеют источник либо явно остаются неизвестными |
| S3 | Построить модель затронутого поведения и проверяемый прогноз, учесть комментарии и инварианты | Названы существенные условия, ожидаемый наблюдаемый эффект и различающий контрпример |
| S4 | Выполнить разрешённое действие, наблюдать результат, сравнить с прогнозом | Изменение реализовано, затронутое поведение проверено подходящим способом; противоречия обработаны |
| S5 | Получить независимую проверку результата в фоновом запуске | Проверка закончилась; доказанные дефекты устранены, блокеры не обозначены как pass |
| S6 | Сверить весь результат с целью, сохранить полезное состояние и сообщить факты | Полный результат и обязательные проверки закрыты либо точно названы непроверенные свойства |

## Привязки и независимость

Следующая стадия `04-bindings.md` связывает каждую обнаруженную возможность с этими шагами, условием и обязательностью. «Обязательно» означает необходимость при выполнении соответствующего условия и доступной применимой возможности, а не требование вызвать весь каталог. Если конкретный механизм назван обязательным в источнике/skill, другой механизм не доказывает исполнение этого требования.

Active rules содержат краткие локальные процедуры и подходящие tools/skills непосредственно в body. Полный каталог служит справочником для discovery и обновляется по фактическому runtime; снимок не создаёт инструментов. Антипаттерны в каждом правиле отделены от положительного контракта. Доставка текста hook и реальное следование модели оцениваются раздельно.
